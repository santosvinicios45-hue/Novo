# Conferidor de E-mail

Abra `index.html` no navegador (dois cliques no arquivo). Cole ou escreva o e-mail e o painel confere antes de você enviar:

- **Destinatários**: campo Para vazio, endereço inválido, domínio digitado errado (`gmial.com`, `.con`…), pessoa repetida.
- **Assunto**: vazio, longo demais, tudo em maiúsculas.
- **Texto**: partes esquecidas para preencher (`{nome}`, `XXX`, `[inserir]`), falta de cumprimento ou despedida, "Bom dia" à tarde, palavra repetida.
- **Datas**: data que não existe (31/02) e dia da semana errado ("quinta-feira, 30/10" quando é sexta).
- **Anexos**: texto fala "em anexo" e não tem arquivo.
- **Modelo**: compara com o seu e-mail padrão — quem falta no Para/Cc, anexos que faltam, assunto diferente e o texto palavra por palavra.

Nos modelos, use `{chaves}` nas partes que mudam a cada envio. Cada modelo pode ter uma lista do que conferir na mão; o carimbo só vira **PODE ENVIAR** quando não há erro, aviso nem item desmarcado.

Modelos e rascunho ficam salvos só no seu navegador (nada é enviado para lugar nenhum).

`conferidor.html` é a mesma página sem o cabeçalho HTML, usada para publicar.
